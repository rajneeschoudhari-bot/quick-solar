## 🚀 How to Run

### Option 1: Direct File Open
Simply double-click `index.html` in your file explorer to open it in Chrome, Edge, Brave, or Firefox.

### Option 2: Python Local Server
Run:
```bash
python server.py
```
Then visit [http://localhost:5050](http://localhost:5050).

### Option 3: Free Cloud Hosting / Deployment
You can deploy this folder directly to:
- **GitHub Pages**: Push this folder to a GitHub repository and enable Pages in settings.
- **Vercel / Netlify**: Drag-and-drop the `rajneesh_portfolio` folder for instant live deployment.
